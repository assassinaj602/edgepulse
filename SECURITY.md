# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in EdgePulse, please do NOT open a 
public GitHub issue.

Instead, email: assassinaj602@gmail.com

We will respond within 72 hours and work with you to resolve the issue 
before any public disclosure.

| Version | Supported |
|---------|-----------|
| 0.x.x   | ✅ Yes    |
