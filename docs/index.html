Central Research Finding

The Thermal-API Blind Spot

Real-device continuous testing on a Tecno CH7n (MediaTek Helio G35) revealed that high-level OS thermal APIs can fail to indicate underlying hardware thermal throttling during sustained LLM workloads.

Key Finding (3) 15-Min Continuous Decoding

+16.5% Latency Regression

Continuous TinyLlama 1.1B GGUF decoding over 15 minutes (441 completions) produced a monotonic mean latency regression from 1,829 ms to 2,131 ms (+301.5 ms penalty per inference).

OS Thermal Status API: nominal (Unchanged)
Physical Latency Shift: +16.5% (Throttling)

Why This Happens

Budget OEM Android distributions (such as Tecno's HiOS) implement PowerManager.currentThermalStatus conservatively for high-level system notifications, missing kernel DVFS frequency scaling under continuous matrix multiplication. Direct application-layer telemetry is essential to capture these degradation effects.

Developer Integration SDK

Instrumenting mobile model inference requires under 10 lines of Dart code. 

import 'package:edgepulse/edgepulse.dart';

void main() async {
  // Initialize EdgePulse native platform channels
  final edgepulse = EdgePulse.instance;
  await edgepulse.initialize();

  // Run model inference under PulseRunner telemetry
  final runner = PulseRunner(
    collector: edgepulse.collector,
    warmupRuns: 5,
    measuredRuns: 30,
  );

  final summary = await runner.run(
    tag: 'mobilenet_v3_tflite',
    callback: () async {
      await tfliteInterpreter.run(input, output);
    },
  );

  // Export structured CSV dataset
  final csv = CsvExporter().exportSummary(summary);
  print(csv);
}
import 'package:edgepulse_core/edgepulse_core.dart';

void main() {
  final trace = InferenceTrace(
    timestampMs: DateTime.now().millisecondsSinceEpoch,
    latencyMs: 148.2,
    memoryPssMb: 409.4,
    thermalState: ThermalState.nominal,
    batteryDrainMah: 849.0,
  );

  final json = JsonExporter().exportTrace(trace);
  print(json);
}
